# Specification

## Summary
**Goal:** Replace the existing “Dark Leather Premium” styling with a logo-aligned navy + gold luxury brand system across the entire frontend, including a premium header redesign and logo integration.

**Planned changes:**
- Update global theme tokens (CSS variables/Tailwind usage) to the new palette: Background #0F1B2D, Secondary Dark #141F33, Gold Accent #C8A24D, Soft Cream Text #F4EFE6, Muted Gold Divider #B9933C; ensure all existing pages/components inherit these values and avoid default bright-blue UI states.
- Redesign the header/navigation for a more luxury feel: transparent overlay on the Home hero with subtle blur, increased spacing, thinner nav typography, and replace the active “filled pill” state with a subtle gold underline/marker (desktop + mobile).
- Integrate the provided MeghRaj Exports logo in the header top-left with premium sizing and clear spacing; ensure it renders sharply and cleanly on dark backgrounds.
- Refine button styling site-wide: gold primary buttons with navy text; gold outline/cream text secondary buttons; smooth hover/focus invert behavior with subtle elevation and theme-aligned focus styling.
- Refresh cards/sections to reduce “boxy template” feel: remove heavy borders, use subtle shadows, add thin gold divider accents, and apply restrained hover interactions (slight zoom + soft gold glow) for key cards.
- Improve typography hierarchy: stronger, refined serif headings and lighter, more spacious body text; apply consistently across navigation, hero, section titles, forms, and content blocks.
- Add subtle luxury detailing across the site: thin gold section separators, optional small gold accent markers for lists, and a very subtle leather-like texture overlay (~5% opacity) on main dark backgrounds.

**User-visible outcome:** The site presents a cohesive navy + gold luxury theme with a premium transparent header over the Home hero, a properly integrated MeghRaj Exports logo, refined typography, buttons, and cards, plus subtle gold detailing and texture depth across all pages.
